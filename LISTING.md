## Fiverr

### Gig title

I will set up an iOS CI/CD pipeline with GitHub Actions, Fastlane, and TestFlight

### Tags

`ios ci cd` · `github actions` · `fastlane` · `testflight` · `swiftlint`

### Gig description

Merging to main should ship a build to TestFlight — automatically. I install a production-grade iOS CI/CD pipeline into your GitHub repository, delivered entirely async as a pull request you review and merge. No calls, no meetings.

**What you get:**

- On every pull request: SwiftLint quality gate, unit tests on a simulator, a code coverage threshold, and one persistent quality report comment on the PR.
- On every merge to main: your app is built, signed, uploaded to TestFlight with auto-generated “What to Test” notes, and archived as a workflow artifact.
- Fastlane and SwiftLint configuration adapted to your project.
- Written setup instructions for every secret and setting.

**Proof:** my public reference repo runs this exact pipeline on itself, with a green deploy run you can inspect: https://github.com/lamtalaa/CICDPipelinePOC

**My guarantee:** if a successful GitHub Actions deploy run does not upload a build to your TestFlight after you merge my PR (with valid secrets), you do not pay.

**How it works:** you invite me as a collaborator, you add your Apple signing secrets to your own repo (I never handle your certificates or keys), I open a pull request, you merge it, and a signed build lands in your TestFlight.

**What you need:** an iOS app that already builds in Xcode, an Apple Developer account, and a GitHub repo. GitHub bills you directly for macOS Actions minutes on private repos.

**Not included:** App Store review approval, fixing compile errors in your app, in-app purchase setup, UI test automation, Android/cross-platform pipelines.

One project at a time — your repo gets my full attention. Flat price: $499.
