# CICDPipelinePOC

A small SwiftUI application demonstrating an end-to-end iOS CI/CD pipeline with GitHub Actions and Fastlane.

## Pipeline behavior

### Pull requests to `main`

- Cancels obsolete runs when a newer commit is pushed.
- Runs SwiftLint as a quality gate.
- Runs unit tests only; the UI test target is intentionally excluded.
- Collects Xcode line coverage and requires the configured threshold.
- Publishes a GitHub Actions job summary.
- Creates or updates one persistent PR quality report comment.
- Uploads SwiftLint, XCTest, `.xcresult`, and coverage reports.
- Sends a Microsoft Teams Adaptive Card when configured.

### Pushes to `main`

After all quality checks pass:

- Uses the `qa-testflight` GitHub environment.
- Assigns a unique build number using `run_number.run_attempt`.
- Generates TestFlight “What to Test” notes from the merged PR or commits.
- Installs temporary signing assets on the hosted runner.
- Builds and signs the IPA with Fastlane.
- Uploads the build to TestFlight.
- Uploads the IPA and release notes as GitHub artifacts.
- Sends the deployment result to Microsoft Teams.

## Repository configuration

### Actions secret

Add this optional secret to enable Teams notifications:

- `TEAMS_WEBHOOK_URL`: URL generated by a Microsoft Teams Workflow using the “When a Teams webhook request is received” trigger.

The existing Apple signing and App Store Connect secrets are still required:

- `APP_IDENTIFIER`
- `APPLE_TEAM_ID`
- `PROVISIONING_PROFILE_NAME`
- `BUILD_CERTIFICATE_BASE64`
- `P12_PASSWORD`
- `BUILD_PROVISION_PROFILE_BASE64`
- `KEYCHAIN_PASSWORD`
- `ASC_KEY_ID`
- `ASC_ISSUER_ID`
- `ASC_KEY_CONTENT`

### Actions variable

- `COVERAGE_THRESHOLD`: minimum application line coverage. Defaults to `70` when the variable is not configured.

### QA environment

Create or configure the `qa-testflight` environment under **Settings → Environments**. Add required reviewers when you want a manual approval before every TestFlight upload.

### Branch protection

Under **Settings → Branches**, protect `main` and require the **Lint, Test, and Coverage** status check before merging.

## Local commands

```bash
bundle install
brew install swiftlint
swiftlint lint --strict
bundle exec fastlane ios test
```

Generated CI reports are written to `ci-results/` and `fastlane/test_output/`.
